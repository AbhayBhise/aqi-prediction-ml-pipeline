## 🎯 What It Does

Most AQI apps show you a number. This one answers the questions that actually matter:

- *"Is it safe to go running right now?"*
- *"What's the safest 2-hour window for outdoor activity today?"*
- *"How much pollution am I being exposed to today?"*

Enter your city, pick your health profile, and get a full 24-hour air quality forecast with personalized guidance — powered by XGBoost and BiLSTM models trained on Indian AQI data.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📊 **Live AQI Forecast** | Interactive charts for 1h, 4h, 6h, 12h, 24h prediction horizons |
| 🏃 **Activity Advisor** | Finds the safest time window for outdoor activity using forecast optimization |
| 💨 **Exposure Score** | Cumulative pollution risk score weighted by AQI severity over 24h |
| 👤 **Risk Profiles** | Tailored recommendations for General / Asthma / Outdoor Worker |
| 🔬 **EDA Explorer** | Explore the data analysis and patterns behind the predictions |
| 🤖 **Model Comparison** | Transparent side-by-side ML model benchmarks |
| 🧠 **AI Summaries** | Natural language air quality outlook generated by LLM |
| 🌙 **Dark / Light Mode** | Smooth theme toggle, preference is saved |

## 🛠️ Tech Stack

**Frontend**
- React 19, React Router v7, Vite 8
- TailwindCSS v4, Framer Motion, Recharts
- Zustand (state management), Axios

**Backend & ML** *(hosted separately)*
- Python, Flask, XGBoost, HistGradientBoosting, PyTorch BiLSTM
- Deployed on Hugging Face Spaces

## 💼 Engineering Highlights

- Built a multi-page React SPA with persistent dark/light theming, Zustand state management, and Framer Motion page transitions
- Integrated a 24-hour AQI forecast dashboard consuming a Flask ML API, rendered as interactive Recharts visualizations
- Implemented a sliding-window activity optimizer that highlights minimum-exposure time windows from forecast data
- Designed a consolidated REST API with Pydantic validation that returns a unified forecast + decision-support payload in a single request
- Deployed to Vercel with GitHub CI/CD; configured SPA routing via `vercel.json` to handle direct URL access
